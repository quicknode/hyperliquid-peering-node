# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability, exposed peer address, credential, or infrastructure identifier. Report it privately through [Quicknode support](https://support.quicknode.com/) and include the affected repository and revision.

Do not include live peer addresses, `.env` contents, rendered configuration, transaction contents, credentials, or private infrastructure logs unless a Quicknode support engineer provides an approved secure channel.

## Operational scope

This repository deploys a customer-operated Hyperliquid node. Operators remain responsible for host access, firewall policy, operating-system maintenance, Docker security, disk retention, monitoring, and downstream data handling.
